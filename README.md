## 📱 如何在手機中使用 / 安裝為 App

本工具為現代化 **Progressive Web App (PWA)**，不需經過 App Store / Google Play 繁複審查，即可在 10 秒內安裝到手機桌面上：

### 方法一：線上專屬網址 (最推薦！出門在外 4G/5G 隨時可用)

1. 在手機瀏覽器中打開您的專屬線上網址：  
   👉 **`https://kof315411-ship-it.github.io/012-Household-expenses/`**
2. **加入手機桌面 (變成獨立 App 圖示)**：
   - **iPhone (iOS Safari)**：點擊瀏覽器底部的 **「分享」按鈕 (箭頭向上方塊)** ➔ 往下滑找到並點擊 **「加入主畫面」** ➔ 點右上角「新增」。
   - **Android (Chrome)**：點擊右上角 **「選單 ⋮」** ➔ 點擊 **「安裝應用程式」** 或 **「新增至主螢幕」**。
3. 手機桌面上即會出現專屬的 **「家用紀錄」** 藍色 App 圖示，點開即為**無網址列、全螢幕**的原生 App 體驗！

*(若線上網址尚未生效，請至 GitHub 儲存庫 `Settings` ➔ `Pages` ➔ `Build and deployment` 的 Source 選擇 `GitHub Actions` 即可立即發布)*

---

### 方法二：在家連同一個 Wi-Fi 快速使用

1. 在電腦上雙擊執行 **`手機Wi-Fi連線開啟.bat`**。
2. 手機連接家中同一個 Wi-Fi，打開手機瀏覽器輸入：  
   `http://192.168.1.164:8000`  
3. 同樣可點選「加入主畫面」使用。

---

## ☁️ 手機更新自動同步至 Google 雲端試算表

1. 在 Google 試算表中，點擊上方選單 **「擴充功能」** ➔ **「Apps Script」**。
2. 打開專案中的 `google_apps_script.js`（或在網頁工具的「⚙️ 雲端設定」點「複製後端腳本代碼」）貼入。
3. 點右上角 **「部署」** ➔ **「新部署」**：
   - 類型齒輪選 **「網頁應用程式」**
   - 執行身分：**我**
   - 誰可以存取：**任何人 (Anyone)**
4. 複製產生的網址，在手機 App 中打開「⚙️ 雲端設定」，貼上並儲存。
5. 此後您在手機上任何時候記帳，資料都會**秒速寫入 Google 試算表**，家人隨時打開雲端表格都能看到最新更新！

## 📊 記帳規則

- **就醫照顧**：分類不需使用，下拉選單為 `看診`、`長照費`、`住院費`、`看護費`、`其他`。老媽金額合併計算，備註自動補上「老媽」。
- **家用繳款**：帳戶與分類不需使用，下拉選單為 `台電`、`中華電信`、`瓦斯`、`北水`、`房貸轉帳`、`墓園管理費`、`其他`。
- **老哥轉帳**：僅抓取 `日期` 與 `換匯後金額 NTD`。
- **僅允許新增（不可修改或刪除）**：為確保家庭歷史帳本真實完整與線上試算表數據安全，本工具採單向記帳設計，僅提供新增紀錄與檢索查閱，無法在前端修改或刪除。
