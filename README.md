# 家庭照顧與家用花費紀錄工具 (Mobile & Web App)

專為手機瀏覽與電腦桌面打造的輕量化開銷與轉帳管理工具，已完整匯入 `家裡、老爸的照顧花費＆照顧紀錄 的副本.xlsx` 的所有歷史帳務。

---

## 🚀 如何快速開啟使用

1. **直接開啟**：
   - 雙擊執行目錄下的 **`開啟工具.bat`** 或直接點擊 **`index.html`**。
   - 任何現代瀏覽器（Chrome、Edge、Safari 等）均可直接開啟，**完全不需安裝任何額外軟體或伺服器**。
2. **在手機上使用 (iPhone / Android)**：
   - 將本資料夾放於雲端硬碟（如 iCloud、Google Drive、Dropbox）或透過區域網路/GitHub Pages 開啟。
   - 在手機 Safari 或 Chrome 中打開 `index.html`。
   - 點擊瀏覽器的「分享」或「選單」→ 選擇 **「加入主畫面」**，即可像一般手機 App 般全螢幕、離線順暢使用！

---

## 📊 資料轉換與規則說明

### 1. 就醫、照顧花費記帳
- **不使用「分類」欄位**。
- **項目下拉選單**：`看診`、`長照費`、`住院費`、`看護費`、`其他`。
- **老媽金額併入**：
  - 原「老媽」欄位之金額已直接併入「金額」一起計算。
  - 有併入老媽金額之紀錄，備註欄已自動補上 **`老媽`**（卡片上會以亮粉色標籤清楚標記）。
- **金額核對**：歷史紀錄共 119 筆，累計總額 **NT$ 2,221,723**（原金額 2,128,451 + 老媽款項 93,272）。

### 2. 家用花費、繳款紀錄
- **不使用「帳戶」、「分類」欄位**。
- **項目下拉選單**：`台電`、`中華電信`、`瓦斯`、`北水`、`房貸轉帳`、`墓園管理費`、`其他`。
- **金額核對**：歷史紀錄共 144 筆，累計總額 **NT$ 1,233,670**。

### 3. 老哥轉帳記錄
- **僅擷取**：`日期`、`換匯後金額 NTD`。
- **金額核對**：歷史紀錄共 47 筆，累計總額 **NT$ 4,161,863**。

## 🛠️ 主要功能亮點

- **📊 總覽儀表板**：老哥轉帳、醫療照顧、家用開銷、累計總結餘即時統計，搭配年度趨勢長條圖與支出類別 TOP 6 排行榜。
- **➕ 快速記帳**：各類別專屬表單，日期預設今日、防呆校驗、自動計算。
- **🔍 即時搜尋與篩選**：輸入關鍵字（例如：「老媽」、「住院」、「永豐」）或切換年份/項目，即時過濾並動態重算小計與筆數。
- **✏️ 編輯與刪除**：卡片上可直接點擊「編輯」或「刪除」，彈出視窗隨時更正。
- **💾 本機自動儲存 (LocalStorage)**：增修資料立即儲存於瀏覽器，重開頁面資料不遺失。
- **📥 備份與匯出**：
  - 支援一鍵匯出 **Excel 相容 CSV**（內嵌 UTF-8 BOM，雙擊 Excel 開啟絕不亂碼）。
  - 支援下載 JSON 完整備份檔與還原。
  - 支援隨時「回復至 Excel 原始資料」。
